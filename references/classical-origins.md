## 使用方法

### 在起名流程中引用

**Step 5（选字）时**，按用户风格偏好翻阅对应源：

| 风格偏好 | 优先查阅的源 |
|---------|-------------|
| 温婉柔美 🌸 | 诗经·国风、girl-classics.md |
| 知性书卷 📖 | 论语、孟子、周易 |
| 自然清朗 🌿 | 唐诗·山水、宋词 |
| 典雅出处 📜 | 楚辞、诗经·雅颂、周易 |
| 现代简约 ⚡ | 唐诗·绝句、宋词·小令 |

**Step 8（析寓意）时**，引用具体出处：
```
┌─ 出处查证
├  "蓁蓁" — 《诗经·周南·桃夭》
│   "桃之夭夭，其叶蓁蓁"
└  推荐：刘蓁蓁 → 有出处，字面自足
```

### 添加新的源

```bash
# 1. 下载原始 json 到 temp_dl/
curl -sL "https://.../source.json" -o temp_dl/source.json

# 2. 在 scripts/parse-classics.js 中添加解析函数
# 3. 在 + 收集 results 对象
# 4. 在 generateMD() 中添加对应章节
# 5. 运行 node scripts/parse-classics.js
```
