# 五行起名参考字库

> 数据来源：康熙字典笔画 + 起名网系字库（James88/qiming 双字典样本）+ 字形象说（邵雍《梅花易数》），2026-09 核验。
>
> **定位**：这是校准参考，不是完整字库。本库精选188个起名常用字并标注五行/笔画/分歧/烂大街度，供 agent 选字时**校准用**。不在本库中的字，agent 按**部首法+字义法**自判五行即可。**188个字远不是起名字的全部**——实际可用字有数千个，本库的作用是标出"坑"（繁简差异、分歧字、烂大街字）。

## 符号约定

- **笔画** = 康熙字典口径（姓名学唯一基准），标注 `(简X/繁Y)` 表示繁简差异大
- `※` = 五行归属有流派分歧，选字时优先避开或向用户说明分歧
- `◆` = 烂大街/新生代重名率高，选字时优先避开
- **风格标签**：现代/古典/大气/柔美/自然/书卷/中性（可多标签）
- 笔画超出 6-18 画的最佳范围者已注明原因

## 使用规则

1. **选字不受此表限制** — 此表不是全部可用字，agent 可以用任何汉字起名
2. **此表的核心价值是校准** — 遇到不在表中的字时，用"部首法+字义法"自判五行，再核对长辈的笔画
3. **遇到 ※ 字** → 优先避开；若必须用，向用户说明"流派分歧"
4. **遇到 ◆ 字** → 默认降权；仅当用户明确要"大众稳妥名"时才启用
5. **笔画一律按康熙口径**，输出时如用户在意数理，同时给简/繁两数
6. **五行补益**：用户给出八字喜用神后，按喜用五行选字，并注明"姓名学属民俗口径，非科学结论"
