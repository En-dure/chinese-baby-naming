## 生肖宜忌逻辑说明

起名选字时，部首的吉凶逻辑来自传统民俗文化：

| 逻辑 | 举例 |
|------|------|
| **喜食** | 鼠牛兔喜"艹米禾"（代表有粮可食） |
| **喜居** | 几乎所有生肖喜"宀"（代表有家可居） |
| **喜贵** | 喜"王玉"（代表尊贵吉祥） |
| **喜合** | 喜三合/六合生肖的字根 |
| **避冲** | 避六冲/六害生肖的字根 |
| **避刑** | 避免自刑/相刑的字根 |
| **避克** | 避五行相克过重的部首 |
