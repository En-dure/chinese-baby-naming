## 声调搭配规则

### 基本原则

| 原则 | 说明 | 反例 |
|------|------|------|
| **抑扬顿挫** | 声调应有起伏变化 | × 张天仙（平平平） |
| **忌全平/全仄** | 三字全平平淡，全仄急促 | × 李奇杰（仄仄仄） |
| **仄起平收** | 首字可仄，末字宜平 | ✅ 赵一鸣（仄仄平） |
| **尾字响亮** | 末字宜用阴平或去声，开口音 | ✅ 浩然、铭泽 |

## 谐音审查（必做）

### 审查流程

```
姓 + 名整体朗读 → 
1. 有无不良谐音（负面词汇谐音）
2. 有无不雅谐音（性、贬义词）
3. 方言谐音（粤语、闽南语、吴语等）
4. 连读是否拗口（声母韵母碰撞）
```

### 常见翻车案例

| 名字 | 谐音 | 问题 |
|------|------|------|
| 杜子腾 | 肚子疼 | 不良谐音 |
| 史珍香 | 史真香 | 不雅谐音 |
| 杨伟 | 阳痿 | 严重不良 |
| 范统 | 饭桶 | 贬义谐音 |
| 朱一 | 主义/猪一 | 歧义 |
| 王囡囡 | 囡=困在"囗"里 | 字形寓意不佳 |

### 声母韵母搭配

避免相邻字出现相同声母或韵母导致的"吃字"现象：

| 问题 | 例 | 说明 |
|------|----|------|
| 声母相同 | 张志忠（zh-zh-zh） | 舌头打结 |
| 韵母相同 | 陈文芬（en-en-en） | 韵母押韵过头 |
| 鼻音冲突 | 林明（m-m） | 双唇鼻音重叠 |

### 五行用字优先级

```
喜用神匹配 → 生肖宜忌 → 笔画适中(8-20画为佳)
→ 字形美观 → 含义正面
```

### 笔画数参考范围

| 考量 | 建议 |
|------|------|
| 单字最佳笔画 | 8~20画（既不过于简单，也不过于繁复） |
| 避免超大字 | >28画的字（如：鑫24、龍16、曦20尚可，䲜等） |
| 避免过简字 | <3画的字（如：一、乙） |
| 姓名总笔画 | 建议在20~45画之间 |
